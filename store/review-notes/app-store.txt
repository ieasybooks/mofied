Mofied is a native React Native app using Expo Video, not an embedded website. No login or payment is required. The production content API is https://faqieh.com/api/v1/mofied/session?locale=ar. Internet access is required.

Launch the app, allow the initial media to load, and tap the media to pause or resume. Swipe up or down to navigate media; required reading pauses must complete before moving forward. On a reading pause, the reading button can pause/resume its countdown. The Info button opens app information, privacy, support, and the Arabic/English interface switch; playback pauses while this sheet is open. Tap a speaker or media title to open its source in the system browser. Backgrounding or locking the app pauses the current session; returning continues it. A new session starts on each launch. The share button (beside Info) opens the system share sheet with a https://mofied.com/?start=ID link; opening such a link starts a session from that media. Info and brief inactive states such as Control Center preserve the current session. The server supplies a finite time budget; the session ends quietly when it is used.

The content is curated Islamic educational media, mostly in Arabic. There are no user accounts, uploads, comments, messaging, ads, or purchases.
